💡 学这门语言的方式

JS 的坑多在「类型」和「隐式转换」，刷题时把每个踩过的类型陷阱记下来。

三个最容易踩的类型陷阱：
  • number 没有 .length，也不能下标访问——要操作位数先 String(x)
  • String(x) 返回新字符串，不修改原变量：let y = String(x)
  • 字符串下标从 0 开始，右指针初始化是 length - 1 不是 length

9
回文数
双指针回文类型转换JS类型简单
我的题解 →

① 题目理解

判断整数 x 是否为回文（正序倒序相同）。负数一定不是（-121 倒过来 121-）。

② 思路：转字符串 + 双指针

数字不好直接比两端，转成字符串后用左右指针向中间扫，不等就 false。

③ 踩坑

JavaScript 类型陷阱：
  • number 没有 .length → 先 String(x)
  • String(x) 返回新字符串，不修改变量：let y = String(x)
  • 右指针是 length - 1 不是 length

④ 代码

var isPalindrome = function(x) {
    if (x < 0) return false;
    let y = String(x);
    let left = 0, right = y.length - 1;
    while (left < right) {
        if (y[left] != y[right]) return false;
        left++;
        right--;
    }
    return true;
};

⑤ 收获 · 双指针模板

回文 / 对称 / 两端比较，都用这个模板： 
let left = 0, right = arr.length - 1;
while (left < right) {
    if (arr[left] != arr[right]) return false;
    left++; right--;
}
LCR 140
链表中倒数第 k 个节点（训练计划 II · 剑指 Offer 22）
链表快慢指针双指针简单
我的题解 →

① 题目理解

给定单链表 head 和整数 k，返回链表中倒数第 k 个节点。

② 思路：快慢指针

  • 让 fast 先走 k 步
  • 然后 fast 和 slow 一起走，fast 到末尾时，slow 正好在倒数第 k 个
  • 一次遍历搞定，时间 O(n)，空间 O(1)

③ 关键点

链表题的通用套路：
  • 「倒数第 k 个」= 快慢指针，快指针先走 k 步
  • 注意边界：k 大于链表长度时 fast 会先变 null
  • JS 里链表就是对象：{val, next}，判空用 !== null

④ 收获 · 快慢指针模板

链表倒数 / 中点 / 环检测，都靠快慢指针：
  • 倒数第 k 个：fast 先走 k 步
  • 找中点：fast 走 2 步、slow 走 1 步
  • 判环：fast 走 2 步、slow 走 1 步，相遇即有环
