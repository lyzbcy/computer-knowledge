学习路径

前端学习资料

微盛研发岗前端方向 · 自学路径。按 JavaScript → Vue3 → Vue-Router → TypeScript 顺序学习，周期约 1 个月。
所有链接均指向官方文档，学完即可上手微盛前端项目（Vue3 选项式 + Element 组件库）。

← 返回学习地图
⚠️ 微盛前端铁律（最重要）

我们采用 Vue3 的 「选项式 API」，禁止使用「组合式 API」。这是为了保持团队代码风格统一。学 Vue3 时请只学选项式写法，不要学 setup() / 组合式。

01

阶段一 · JavaScript 基础

前端的一切基础。如果你只会 C/Java，先过一遍 JS 的语法、类型、函数、异步（Promise/async）。这是后续 Vue3 的地基。

📚 推荐资源

JavaScript 基础入门 — 腾讯云开发者社区
内部推荐的第一份 JS 入门材料，覆盖语法、数据类型、函数、DOM、事件、异步等基础。

💡 学到什么程度够用

能看懂 Vue3 单文件组件里 script 部分的写法（data/methods/computed/watch），理解 this 指向、箭头函数、Promise。不用深究原型链等进阶。

02

阶段二 · Vue3（核心）

微盛前端的核心框架。重点学选项式 API，按下面的章节顺序学。

📚 官方文档

Vue3 官方指南 →

📖 重点章节（必学）
板块范围说明
基础全部模板语法、响应式、条件/列表渲染、事件、表单、组件基础——地基，全学
深入组件全部组件注册、Props、事件、插槽、Provide/Inject——日常开发高频
应用规模化单文件组件.vue 文件结构（template/script/style）
路由配合 Vue-Router（阶段三细学）
状态管理Pinia/Vuex，了解概念即可
进阶主题渲染机制理解虚拟 DOM
渲染函数 & JSX了解即可，选项式很少用
TypeScript 总览 + TypeScript 与组合式 API

官方文档里这两节也会带到 TS，先扫一遍，阶段四系统学。

03

阶段三 · Vue Router

前端路由。微盛是 SPA（单页应用），页面切换靠 Router。学完能看懂项目的路由配置。

📚 官方文档

Vue Router 入门 →

📖 重点章节（必学）

基础全部 + 进阶全部。重点：动态路由匹配、嵌套路由、编程式导航、导航守卫（路由拦截，鉴权常用）。

04

阶段四 · TypeScript

带类型的 JS。微盛项目用 TS，看代码时会遇到类型标注。重点是能看懂类型定义，不必精通。

📚 官方文档

05

学习节奏建议

📅 一个月分配（建议）
周重点目标
第1周JavaScript 基础能看懂 JS 代码，理解异步
第2周Vue3 基础 + 深入组件能写一个简单的 .vue 组件
第3周Vue-Router + 应用规模化能看懂项目路由和组件结构
第4周TypeScript能看懂项目里的类型标注
💡 配合实操

学 Vue3 时，配合「设计稿转前端代码」（AICoding）一起练——用 Skill 把设计稿转成代码后，读它的 .vue 文件结构，对照 Vue3 文档理解每一部分。这是最快的上手方式。
