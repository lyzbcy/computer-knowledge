771
宝石与石头
Java基础String字符遍历HashSet简单
Java

① 题目理解

给定 jewels（宝石类型）和 stones（拥有的石头），统计 stones 里有多少个字符属于 jewels。字母区分大小写，jewels 字符不重复。

例：jewels="aA"，stones="aAAbbbb" → 结果 3（a×1 + A×2）。

② 思路

  • 暴力枚举：双层循环，遍历每个 jewel，去 stones 里找。时间 O(m×n)，空间 O(1)。
  • HashSet 优化：把 jewels 放进 Set，遍历 stones 判断在不在 Set 里。时间 O(m+n)，空间 O(m)。

③ 踩坑（JS → Java 必踩）

这道题的核心坑，全是 Java String 的：
  • 字符串长度用 .length() 不是 .length（JS 是属性，Java 是方法）
  • 取字符用 .charAt(i) 不能用 jewels[i]（Java String 不能下标访问）
  • 判断循环结束用 i < jewels.length()，没有 null 结束符（别带 C/C++ 思维）

④ 代码

// 方法一：暴力枚举 O(m×n)
class Solution {
    public int numJewelsInStones(String jewels, String stones) {
        int sum = 0;
        for (int i = 0; i < jewels.length(); i++) {
            for (int j = 0; j < stones.length(); j++) {
                if (jewels.charAt(i) == stones.charAt(j)) {
                    sum++;
                }
            }
        }
        return sum;
    }
}

⑤ 收获

可复用的判断：
  • 遇到「判断字符是否存在 / 两个集合比较 / 查重复」→ 优先考虑 HashSet / HashMap，哈希结构通常比暴力更优
  • Java String 的三个基础 API：.length()、.charAt(i)、String ≠ char[]

回文数 · JavaScript 版
双指针回文类型转换JS类型简单
JavaScript

① 题目理解

判断整数 x 是否为回文（正序倒序相同）。负数一定不是回文（-121 倒过来 121-）。

② 思路：转字符串 + 双指针

数字不好直接比两端，转成字符串后用左右指针向中间扫，不等就返回 false。

③ 踩坑

JavaScript 类型陷阱：
  • number 没有 .length，要先 String(x) 转成字符串
  • String(x) 返回新字符串，不修改原变量：let y = String(x) 而不是 String(y)
  • 右指针初始化是 length - 1 不是 length（下标从 0 开始）

④ 代码

// JavaScript · 双指针
var isPalindrome = function(x) {
    if (x < 0) return false;
    let y = String(x);
    let left = 0, right = y.length - 1;
    while (left < right) {
        if (y[left] != y[right]) return false;
        left++;
        right--;
    }
    return true;
};

⑤ 收获 · 双指针模板

遇到回文 / 对称 / 两端比较，优先用这个模板： 
let left = 0, right = arr.length - 1;
while (left < right) {
    if (arr[left] != arr[right]) return false;
    left++; right--;
}
后面的「反转字符串」「验证回文串」都是它的变形。

① 同一道题，Java 再做一遍

把 JS 版迁移到 Java，重点不是算法（一样），而是语言差异。

② 关键差异

操作JavaScriptJava
数字转字符串String(x)String.valueOf(x)
字符串长度y.lengthy.length()
取字符y[left]y.charAt(left)

③ 踩坑

Java 额外的坑：
  • valueOf 别拼成 value0f（大写 O 不是数字 0）
  • String.valueOf(x) 返回新对象，要赋值：String y = String.valueOf(x)

④ 代码

// Java · 转字符串 + 双指针
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        String y = String.valueOf(x);
        int left = 0, right = y.length() - 1;
        while (left < right) {
            if (y.charAt(left) != y.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}

⑤ 收获

  • 9 → 用 Java String + 双指针完成完整题目
